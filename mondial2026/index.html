Comment importer le fichier .ics dans mon agenda ?

Google Agenda (ordinateur) : ouvre agenda.google.com → roue dentée ⚙️ Paramètres → Importer et exporter → sélectionne le fichier .ics téléchargé → choisis l'agenda de destination → Importer. Tous les matchs cochés apparaissent d'un coup.

Apple Calendar (iPhone / Mac) : ouvre simplement le fichier .ics téléchargé ; Calendrier propose d'ajouter les événements. Sur Mac, tu peux aussi le glisser dans l'app Calendrier.

Outlook / Proton / autres : cherche l'option Importer un calendrier (ou « Importer .ics ») dans les réglages et sélectionne le fichier.

Astuce : chaque match garde un identifiant stable — réimporter une version mise à jour du fichier met à jour les événements existants au lieu de créer des doublons (pratique quand les affiches des phases finales se précisent).
